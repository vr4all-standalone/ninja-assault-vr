# Ninja Assault VR design

User request (2026-10-25): make another VR mod for Ninja Assault the same way, with all the same features as the completed Confidential Mission and Lupin ports.

Build a separate standalone Quest and PC OpenXR application from finished Lupin commit f67026046. Preserve both reference projects. Match the inherited paused menu (Resume, Recenter, Gun, Gun angle, Reload, Hands, Laser, Haptics, World size, Panel distance, Wider view, How to play, Quit), settings persistence, controller labels/profiles, P1 hand choice, P2 join/leave, accepted-round feedback, cutscene empty hands, gun models and user GLBs, comfort and model preparation/fallback behavior. Adapt camera, hit-test projection, HUD, calibration, Namco JYU input, ammo and lifecycle from measured Ninja Assault data. No copied Lupin or CM addresses may be treated as Ninja evidence.

Builder decisions: initial measured target World NJA2 Ver.A (ninjaslt.zip); investigate other supplied region sets only if their code guards match. Application com.vrlightgunhub.ninjaassault, title Ninja Assault VR, base version 1.0.0, Quest artifact ninja-assault-vr-quest.apk, PC ninja-assault-vr-pcvr.zip, launcher Play Ninja Assault.cmd. Keep own config, saves and extracted caches. Game is cartridge-based, not a GD-ROM: require own game ZIP and NAOMI BIOS; investigate and validate regional clone/parent pairing. Use local user ROMs at E:/___flattovrdev/confidential mission/Roms for private testing; never change originals or put game data/captures/extracted models in tracked source or distributable archives.

Deliver local builds plus prepared PC play folder and validation notes. Existing licensed bundled Arcade/Zapper/controller models may be reused with unchanged credits and licence notices. New in-game extraction requires identifying an actual complete Ninja weapon; do not pass another game's model off as native. Native gun availability must be honest if no eligible model is observed. Record any incomplete parity as outstanding work. Publishing, headset installation and new automations are outside this request. Physical headset testing must remain explicitly unverified until actually performed.

Research and implementation can be separated by ownership: Android file/setup/identity; native camera/state/render/input; packaging and verification. All measurements and acceptance criteria must be recorded. Stop only for a genuine blocker; continue independent work while any question is pending.
