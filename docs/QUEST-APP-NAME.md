# Quest application name

The Quest application/library label is `Ninja Assault - VR4ALL`. Preserve this name, existing package ID and existing signing identity in future builds.

This release only updates the Android manifest label and package version. The accepted prior release native/DEX/resources/assets and the PC VR archive are unchanged. The native revision suffix in the APK version identifies the unchanged native baseline; the release tag additionally records the branding/packaging metadata update. Build normally from the corresponding updated source to retain the label. The complete original MAME/dependency source and branding manifest/Gradle changes are in the source ZIP where supplied.
